# Invitations build kit
The kit this project is built from (it was unzipped at the repo root). Start with `docs/invitations/KICKOFF.md`.
- `docs/invitations/MASTER_PROMPT.md` — full spec: product, contracts, design, build phases, tests
- `docs/invitations/design-reference/` — invitation.html + app.html + screenshots (look & feel source of truth)
- `docs/invitations/fixtures/`, `docs/invitations/i18n/`, `docs/invitations/icons/`
- `docs/invitations/production/` — asset production kit (AI prompts, ffmpeg) + Hebrew product spec
- `invitation-templates-pack/` — 8 templates (manifest + HE/EN defaults + asset checklist)
